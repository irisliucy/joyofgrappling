Privacy Policy

Joy of Grappling ("JoG") — last updated 2026-09-10

What this tool does

Joy of Grappling is a research tool that searches YouTube for Brazilian Jiu-Jitsu instructional and competition videos related to a position or technique you specify, and extracts structured technique information from publicly available video metadata and transcripts.

Information we collect

We do not require accounts, logins, or any personal information to use this tool. The only input you provide is a search query (a technique or position name, and optionally a player name), which is used solely to search YouTube and is stored only to let you view your own past research results.

Use of the YouTube API Services

This application uses the YouTube API Services to search for videos and retrieve their public metadata (title, channel name, publish date, view count) and publicly available captions/transcripts. We use this data only to rank relevance and extract technique information for display back to you, linked to and embedded from the original YouTube video via the standard YouTube embed player. We do not download, redistribute, or store video or audio content itself.

By using this application, you are also agreeing to be bound by the YouTube Terms of Service.

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. For more on how Google handles your data generally, see the Google Privacy Policy.

Data storage

Search queries, extracted technique data (positions, moves, transitions), and source video metadata (titles, channel names, URLs, timestamps) are stored in our database to build and display the technique graph. This data is derived from publicly available YouTube content and does not include any personal data about you as a user of this tool, beyond the query text you typed.

Third-party services

This tool also sends video transcript text to Anthropic's Claude API for technique extraction, subject to Anthropic's Privacy Policy.

Contact

Questions about this policy can be directed to the maintainer of this project via its GitHub repository.
